Prompt 3
--------------------------------------------------
Eres un experto desarrollador de frontend con bootstrap y backend con spring boot.
Crea un formulario de matricula.
Los campos del formulario son:
- IdCurso: se trata de un campo numerico entero mayor que cero.
- idAlumno: se trata de un campo numerico entero mayor que cero.
- tipo: se trata del tipo de matricula y puede tomar los siguientes valores "REGULAR", "MEDIABECA", "BECA".
- cuotas: se trata de un campo numerico entero mayor que cero, su valor puede ser 1, 2 o 3..
Ademas de estos campos tambien se debe incluir el campo "idEmpleado" al objeto JSON en la llamada al servicio rest, el valor de "idEmpleado" es un valor en duro,y es el valor 3.
El servicio rest para procesar es formulario es "http://localhost:8080/educa/matricular" y el tipo de llamada es post.
Recuerda que debes usar bootstrap.
Si tienes alguna duda, puedes realizar las preguntas pertinentes, pero, una por una.
